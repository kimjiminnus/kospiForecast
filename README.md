# Custom Transformer and LSTM vs Google's TimesFM 2.5 for time-series analysis & forecasting of market indices
*Custom Transformer Encoder accepts input tensors of shape (batch_size, window, num_vars)
**Encoder uses causal mask for autoregressive forecasting of the KOSPI Index using various windows
**A Hugging Face-style Pipeline and Trainer has been created for simplified training, evaluation, inference and visualisation.
